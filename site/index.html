01. About

I'm a DevOps engineer based in Germany, focused on automation that actually saves time: CI/CD pipelines that deploy on every push, container images that run anywhere, and servers that heal themselves.

My day-to-day toolkit spans the full lifecycle — from writing the application (Python, Ruby on Rails, React) to packaging it (Docker, multi-platform builds) to running it (AWS EC2, Render, Vercel, Nginx, systemd). I believe infrastructure should be boring, repeatable, and version-controlled.
